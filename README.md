# subscription-retention-analysis
# 온라인 교육 콘텐츠 구독 서비스: 전환 · 이탈 분석

온라인 교육 구독 서비스의 이벤트 로그(가입 · 결제 · 구독 · 콘텐츠 · 레슨)로 유저가 언제 이탈하고, 어떤 학습 경험이 구독 유지로 이어지는지 분석한 팀 프로젝트입니다.

- **기간:** 코드잇 부트캠프 데이터분석과정 팀 프로젝트
- **내 역할:** 시계열 코호트 분석
- **사용 기술:** Python (pandas, numpy, matplotlib, seaborn)

## 분석 질문
1. 시기 · 유저군(첫 구독 · 갱신 · 재구독)별로 유지 패턴이 어떻게 다른가
2. 유지율이 가장 크게 떨어지는 구간은 어디인가
3. 구독 첫 달의 학습 경험이 이후 유지와 관련이 있는가

## 분석 방법
| 구분 | 내용 |
|---|---|
| 분석 기간 | 2023.05 ~ 2023.12 (무료체험 폐지 이후 구간) |
| 코호트 | 첫 구독 · 갱신 · 재구독 각각 첫 이벤트 월 기준 |
| 유지 정의 | 이후 달에 갱신 결제가 있으면 유지, 관측 기간을 넘는 칸은 제외 |
| 학습 지표 | 구독 첫 달 레슨 완료 수, 첫 콘텐츠 난이도 |

## 주요 결과
- 월 가입 유저는 4,739명(5월)에서 9,474명(12월)으로 늘었습니다.
- 갱신 코호트의 1개월 차 유지율은 44~61%로, 코호트마다 절반 가까이가 첫 달에 이탈했습니다.
- 대부분의 유저가 3개월을 넘기지 못해, 원인을 구독 전후의 학습 경험에서 찾았고 이 결과가 팀의 Aha Moment 가설 검증으로 이어졌습니다.
